# Real Hardware Photos

This directory is reserved for photographs of the actual hardware used in the TUL MCU Firmware Reader project.

Planned photo groups:

- TUL enclosure and finished instrument
- PanLee ZX3D50CE08S-V16-USRC main board
- WT32-S3-WROVER module
- J5 I/O connector and pin identification
- ATmega328P-AU target board
- Target-side wiring and test setup
- Measurement points and measured voltages
- Successful ISP test output/setup

The user will provide the final photographs later. Add them without removing earlier evidence. Use descriptive filenames such as `tul-j5-front.jpg` or `atmega328p-target-pin15.jpg`.
