# Reference Images

This directory stores versioned diagrams and reference illustrations used by the documentation.

## Current assets

- `atmega328p-tqfp32-isp-pinout.svg` — reference diagram showing the ATmega328P TQFP-32 ISP pins used by the first proof-of-concept.
- `tul-j5-atmega328p-wiring.svg` — reference wiring diagram for the first bench connection.

## Real photographs

Photographs of the actual TUL enclosure, PanLee board, J5 connector, target logic-probe PCB, and measured wiring will be added later under `docs/photos/` when the user supplies the final images.

Do not replace measured/actual photographs with generic internet images. Reference diagrams and actual hardware photographs have different purposes and should be labelled accordingly.
